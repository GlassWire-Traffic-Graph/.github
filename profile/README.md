## What Is GlassWire

GlassWire is a personal traffic view for one computer and the small network around it. GlassWire traffic graph and GlassWire bandwidth describe what this machine is doing. GlassWire ask alert is the moment a program asks to connect and you decide whether that fits the work you are doing. A home user or a small office can understand their own computer without a separate security department.

GlassWire device list is the neighborhood of devices on the network you use, such as a home LAN. GlassWire firewall view is where allow and block choices for local programs are visible. The helper is for awareness of your own traffic. It is not a guide for breaking into other machines or for hiding activity.

Use it as a daily glance. Open GlassWire traffic graph, notice GlassWire bandwidth, and answer GlassWire ask alert when a program is new to you. Check GlassWire device list if a home network suddenly looks crowded, and review GlassWire firewall view when you want to see which local programs are allowed to talk.
